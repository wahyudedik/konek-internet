🔧 DNS Endpoints (9)

GET /dns/{domain}

Query DNS records untuk domain. Parameter: record_type (A, AAAA, MX, TXT, CNAME, NS)

Contoh Request & Response
Request:
GET /api/v1/dns/google.com?record_type=A
Response:
{
    "domain": "google.com",
    "record_type": "A",
    "records": ["142.250.4.46", "142.250.4.42"]
}
GET /dns/{domain}/reverse

Reverse DNS lookup — temukan hostname dari IP address.

Contoh Request & Response
Request:
GET /api/v1/dns/8.8.8.8/reverse
Response:
{
    "ip": "8.8.8.8",
    "hostname": "dns.google"
}
GET /dns/{domain}/mx

Cek Mail Exchange records untuk domain.

GET /dns/{domain}/txt

Cek TXT records termasuk SPF, DKIM.

GET /dns/{domain}/cname

Cek CNAME records untuk domain.

GET /dns/{domain}/spf

Validasi SPF record untuk domain.

GET /dns/{domain}/dmarc

Validasi DMARC policy untuk domain.

GET /dns/{domain}/propagation

Cek propagasi DNS dari 7 nameserver global. Parameter: record_type

GET /dns/{domain}?record_type=NS

Cek Name Server (NS records) untuk domain.

🌍 Domain Endpoints (2)

GET /whois/{domain}

Informasi lengkap registrasi domain: registrar, tanggal, expiry, nameserver.

Contoh Request & Response
Request:
GET /api/v1/whois/google.com
Response:
{
    "domain": "google.com",
    "registrar": "MarkMonitor Inc.",
    "created": "1997-09-15",
    "expires": "2028-09-14",
    "nameservers": ["ns1.google.com", "ns2.google.com"]
}
GET /domain/{domain}/expiry

Cek sisa waktu aktif domain.

🔒 SSL Endpoints (2)

GET /ssl/{domain}

Verifikasi sertifikat SSL: issuer, expiry, validity, serial number.

Contoh Request & Response
Request:
GET /api/v1/ssl/google.com
Response:
{
    "domain": "google.com",
    "valid": true,
    "issuer": "GTS CA 1C3",
    "not_before": "2024-01-01",
    "not_after": "2024-03-25",
    "days_remaining": 82
}
GET /ssl/{domain}/expiry

Cek sisa waktu aktif sertifikat SSL.

🌐 Website Endpoints (5)

GET /ping/{host}

Uji konektivitas dan response time ke host.

Contoh Request & Response
Request:
GET /api/v1/ping/google.com
Response:
{
    "host": "google.com",
    "status": "ok",
    "response_time_ms": 12.5,
    "ip": "142.250.4.46"
}
GET /http-status/{url}

Cek status HTTP response (200, 301, 404, dll).

GET /redirect/{url}

Lacak rantai redirect dari URL awal ke URL final.

GET /headers/{url}

Analisis HTTP headers: Content-Type, Cache-Control, Security headers.

GET /ua/{user_agent}

Parse dan analisis User-Agent string. Bisa juga GET /ua untuk auto-detect.

📡 IP Endpoints (6)

GET /ip/me

Deteksi IP address Anda saat ini (auto-detect).

GET /ip/{ip_address}

Informasi lengkap IP address: lokasi, ISP, timezone, organisasi.

Contoh Request & Response
Request:
GET /api/v1/ip/8.8.8.8
Response:
{
    "ip": "8.8.8.8",
    "country": "United States",
    "region": "California",
    "city": "Mountain View",
    "isp": "Google LLC",
    "org": "Google LLC",
    "as": "AS15169"
}
GET /ip/{ip_address}/asn

Cek Autonomous System Number dan organisasi jaringan.

GET /ip/{ip_address}/blacklist

Cek apakah IP address ada di blacklist email/abuse.

GET /email/{email}/validate

Validasi email address: format, MX record, disposable detection.

GET /port/{host}?ports=80,443,22

Scan port TCP pada host. Parameter: ports (pisahkan koma).

⚠️ Error Response

{
    "error": "Deskripsi error dalam Bahasa Indonesia"
}

HTTP Status Codes: 200 (OK), 429 (Rate Limit), 404 (Not Found), 500 (Server Error)
